The Eclipse Dataspace Hub is maintained by its community. It is a place for developers and adopters to meet, and it grows with what they contribute: corrections, lectures, samples, and demonstrators.

## Ask and discuss

- **Chat.** The EDC community runs a [Discord server](https://discord.gg/n4sD9qtjMQ). The `#dataspace-hub` channel is the place for questions about this hub, the learning paths, and the demonstrators.
- **Issues.** Report problems with a demonstrator in its own repository: [JAD](https://github.com/eclipse-dataspace-hub/jad/issues) or [Minimum Viable Dataspace](https://github.com/eclipse-dataspace-hub/MinimumViableDataspace/issues).
- **Project contact.** The [project page](https://projects.eclipse.org/projects/technology.dataspace-hub) at the Eclipse Foundation lists the project leads and committers.

Questions about a specific component are best asked in that component's project. The [overview](../#documentation-and-source-repositories) links to their documentation and repositories.

## Give feedback on the learning paths

The learning paths are meant to be read by people who are new to the subject. If a lecture left you with a question, used a term it did not explain, or described something that no longer matches the software, that is useful to know. Open an issue or mention it in the chat, and say which lecture you were reading and what you were trying to do.

## Contribute

Contributions of every size are welcome:

- fix an error or a broken link;
- improve an explanation;
- propose a new lecture or a new path;
- add a sample or extend a demonstrator.

The Hub follows three rules for content:

1. **Orient, then link.** A lecture explains how things fit together and links to the authoritative documentation for detail. It does not copy reference material from other projects.
2. **Fix upstream.** When a sample or demonstrator reveals a bug or a gap in a component, the fix goes to that component's project.
3. **Teach, do not ship.** Demonstrators and samples are for learning. They are not hardened for production use.

As with every Eclipse project, contributors need an Eclipse account and a signed [Eclipse Contributor Agreement](https://www.eclipse.org/legal/eca/).

## About the project

The Eclipse Dataspace Hub lowers the entry barrier to dataspace technologies such as the Eclipse Dataspace Components, the Connector Fabric Manager, and data plane implementations. It has three areas of work:

- **Knowledge base**: this site, with its learning paths and orientation pages.
- **End-to-end demonstrators**: runnable examples of cross-organizational data sharing.
- **Sample code and templates**: reference implementations for common extensions and integrations.

The project is in the incubating phase at the Eclipse Foundation, is affiliated with the [Eclipse Dataspace Working Group](https://projects.eclipse.org/working-group/eclipse-dataspace), and is licensed under the Apache License 2.0.
